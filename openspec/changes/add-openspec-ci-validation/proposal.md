## Why

Репозиторий использует OpenSpec, но корректность его артефактов не проверяется автоматически в GitHub. Из-за этого структурная ошибка может быть объединена с основной веткой незамеченной.

## What Changes

- Добавить отдельный GitHub Actions workflow строгой проверки OpenSpec.
- Запускать проверку при изменениях `openspec/**` в Pull Request и основной ветке.

## Capabilities

### New Capabilities

Нет: меняется только контроль качества репозитория.

### Modified Capabilities

Нет.

## Impact

- Поведение Telegram-бота и его зависимости не меняются.
- Секреты не используются.
- Откат: удалить добавленный workflow.
