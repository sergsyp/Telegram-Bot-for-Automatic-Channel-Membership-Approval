# Telegram-бот для автоматического принятия заявок

Бот автоматически принимает заявки пользователей на вступление в Telegram-канал или группу и отвечает на команду `/start`. Рабочая версия развёрнута на [BotHost](https://bothost.ru/) и использует библиотеку `python-telegram-bot`.

## Возможности

- работа через Telegram long polling;
- автоматическое одобрение заявок на вступление;
- ответ на команду `/start`;
- запуск в Docker на BotHost;
- хранение токена вне исходного кода.

## Настройка токена на BotHost

Токен нельзя записывать в `config.py`, `.env` или другой файл проекта на площадке: при следующем деплое такой файл может попасть в Git либо быть перезаписан.

Откройте карточку бота в BotHost, затем раздел **Переменные окружения** и добавьте:

```text
BOT_TOKEN=<токен, полученный у @BotFather>
```

При необходимости там же задайте имя канала:

```text
CHANNEL_USERNAME=@имя_канала
```

После сохранения переменных перезапустите бота. Код получает токен из `BOT_TOKEN`; если переменная отсутствует, запуск завершится с понятной ошибкой.

> Если токен когда-либо был записан в код открытым текстом, перевыпустите его через @BotFather и замените значение `BOT_TOKEN` на BotHost.

## Локальный запуск

Требуется Python 3.11 или новее.

```bash
git clone https://github.com/sergsyp/Telegram-Bot-for-Automatic-Channel-Membership-Approval.git
cd Telegram-Bot-for-Automatic-Channel-Membership-Approval
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Linux/macOS:

```bash
export BOT_TOKEN='токен_бота'
export CHANNEL_USERNAME='@имя_канала'
python main.py
```

Для Windows PowerShell:

```powershell
$env:BOT_TOKEN='токен_бота'
$env:CHANNEL_USERNAME='@имя_канала'
python main.py
```

Файл `.env.example` содержит только безопасный шаблон. Настоящий `.env` исключён из Git и не должен коммититься.

## Развёртывание

BotHost собирает проект по `Dockerfile` и запускает команду:

```text
python main.py
```

Перед развёртыванием проверьте, что бот добавлен администратором в нужный канал или группу и имеет право приглашать пользователей или одобрять заявки.

## Структура проекта

- `main.py` — обработчики Telegram и запуск бота;
- `config.py` — чтение настроек из переменных окружения;
- `requirements.txt` — зависимости Python;
- `Dockerfile` — контейнер для BotHost;
- `.env.example` — шаблон локальных переменных без секретов.

## Безопасность

- не публикуйте токен в GitHub, Telegram, логах или скриншотах;
- храните рабочий токен в переменной окружения `BOT_TOKEN` на BotHost;
- при утечке немедленно перевыпустите токен через @BotFather.
